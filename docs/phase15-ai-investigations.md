# Governed Catalog and Pricing investigations

Checkpoint 15H extends the existing Master Analyst, native MCP transport and
finding lifecycle. It introduces no ordering, pricing activation, publishing,
manufacturing or financial execution tool.

Select **Catalog and Pricing** in AI Analyst. A contribution investigation first
discovers an authorized disclosure sample, retrieves reviewed Pricing publications,
reads their original evidence, and requests a deterministic comparison. A cost
description can use the existing scientific service. Accepted-line demand
descriptions select Sales publications with the same exact offering revision,
currency and channel; missing orders and days remain unknown. They are not demand
forecasts or causal promotion analyses.

Choose Business disclosures or Synthetic demonstration disclosures explicitly.
The investigation's `catalogPurpose` fixes that read-only filter; the model cannot
silently widen it to mixed audiences. Synthetic results must say they are
synthetic. Access permissions remain independently enforced for either audience.

The model emits every native call and argument. The planner only narrows the
already discovered read-only tool set and requires observed source identities and
evidence. It does not create calls, grant authority or manufacture results.
Conditional estimates must retain source-formatted monetary values, quantities,
currency, declared cost scope, pricing context, origin coverage and leases.
Similar names and compatible analytical cohorts establish neither product nor
supplier identity. Coordinated purchasing savings require additional approved
supplier/specification evidence; they are not inferred from Catalog labels.

## MCP tools

- `query_catalog_summary`: at most eight exact reviewed source publications;
  disclosed types and Sales samples describe this sample, not a company census.
- `query_catalog_publications`: at most four results, with offering/Pricing/Sales
  kind filters and bounded underlying page scans.
- `get_catalog_evidence`: at most four compact source facts per page. The complete
  immutable original evidence set remains retained for independent calculations.
- `compare_catalog_contribution`: two to four exact Pricing references;
  independently recomputes costs and conditional contribution, preserving unknowns.
- `compare_catalog_contribution_pair`: an additive named `first`/`second` form of
  the same calculation. Both are complete six-field references. The original
  array contract remains supported; the paired form helps smaller native models
  generate valid calls without changing authority or accepting malformed output.
- `analyze_catalog_statistics`: existing Python descriptive calculations over
  compatible reviewed price/cost observations, including exact mean fractions.
- `analyze_catalog_demand`: existing Python accepted-line quantity descriptions
  over distinct same-offering/channel observations.
- `get_catalog_result`: retained owner-scoped calculation with renewed source
  authorization. Historical values do not grant current transactional authority.

References always include entity, Worker installation, module, stream, record and
revision. Scope is checked before access and again during investigation/readback.
Model-only views omit layout and duplicate scope metadata; original tool results,
native calls, full references and calculation evidence remain in activity/storage.
Publication lookup's optional `analysis=comparison|statistics` selects a read-only
investigation step. It is not a financial approval. Default comparison offers one
named-pair calculation tool; statistics intent offers the existing scientific tool.

## Review and delivery

A completed, validated investigation creates no finding automatically. A registry
administrator must explicitly review it and submit `{reviewed:true}` through the
existing finding action. Master reloads the owned immutable calculation, verifies
current complete original sources and independently reconciles its arithmetic.
Concurrent retries return the same finding. Incomplete evidence, unknown origin,
incompatible comparisons and quantity-only descriptions cannot become financial
recommendations.

The existing signed durable synchronization system delivers only to the exact
source Worker installations. A second Worker of the same legal entity receives no
unrelated packet. Each Worker sees its own conditional observations and references;
other companies' cost figures and ecosystem comparison text stay at Master.
Current verified original module identity and its declared read permission are
checked locally on finding reads and acknowledgment. Disabling accounts, revoking
permissions, replacing the original provider, or removing trust cannot bypass
these boundaries. Existing mission and financial finding restrictions remain.

Worker operation and local acknowledgment do not require Master connectivity.
Pending receipts use the existing durable outbox. Expired or withdrawn sources
cannot authorize a new financial finding; retained historical evidence is not
deleted.

## Failure handling and local models

Use the existing private Analyst provider configuration and TLS trust setup.
Per-call model deadlines, tool deadlines, total investigation time, steps, tool
calls and context size remain separate bounded settings. A malformed response,
provider failure, timeout, unobserved reference or exhausted budget produces a
failed/partial investigation with retained activity, never an invented result.
Only one native-protocol repair and one evidence correction are permitted.

`SOURCE_EVIDENCE_UNAVAILABLE` indicates that an original source changed, expired
or became unavailable during investigation. `INVESTIGATION_SCOPE_REVOKED`
indicates that current access no longer permits its source scope. Ordinary
Catalog/Pricing administration remains available during model/scientific outages.

The reproducible protocol test model is explicitly labeled and does not establish
model quality. Real Qwen verification must use the installed Ollama model through
actual native calls, retain its model digest and transcript, restore configuration
and unload any model loaded solely for the test. Synthetic source fixtures do not
establish installed-package routing or live Shopify/Printify compatibility.

Verification commands:

```powershell
npm run test:catalog:mcp
npm run test:catalog:findings
npm run test:catalog:analyst
npm run test:catalog:planning
npm run test:catalog:analyst:browser
npm run verify:catalog:ollama
```

The Ollama harness creates a private disposable TLS bridge and isolated fixture
installation, rather than changing the selected operator's provider files. It
requires the existing `qwen2.5:7b` model and its installed 16k-context alias. Its
source records are explicitly generated test fixtures. It records actual native
calls and independent calculation checks, restores environment configuration and
unloads only the model it loaded for the run. A failure is retained as a failed
report and cannot count as real-provider acceptance.

## Model-facing discovery controls

The Analyst's staged model view of `query_catalog_summary` and `query_catalog_publications` offers bounded search/pagination, disclosure purpose/status, and publication kind/analysis controls. It omits optional entity/date/currency filters from that model-facing schema to avoid empty-value calls from smaller local models. The original MCP registrations and API schemas retain those filters for direct authorized callers; no supplied arguments are coerced, defaulted into authority, or silently accepted when invalid. The model view is cloned without changing the discovered descriptor, fails closed if a future schema makes an omitted field required, and preserves all bounds. Evidence and calculation tools retain their complete source-reference schemas. Calculations still enforce compatible currency, unit, cohort and source scope; a broader discovery sample is not evidence of a complete census or permission to compare incompatible observations. Original MCP failures remain in activity and bounded native feedback so a model can repair its arguments; repeated identical calls still fail.
