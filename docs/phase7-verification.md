## Production limitations

This is an MVP on the established local Docker provider and operator-managed signed file catalog. It is not a highly available module registry, multi-host scheduler, complete accounting/HR/payroll system or production certification. Only synthetic Workforce data is supported. Business quantities/currencies use the documented module conventions; unit/currency conversion and reinterpreting populated data are unsupported. Resource analysis currently uses m³ and explicit operational/commercial assumptions. Candidate matching is simple local skills matching, with aggregate ecosystem opportunities and human consent/review. Backup/restore, broader performance/security assessment, operational rollout controls and production TLS/secret rotation remain deployment responsibilities. Deferred offline enrollment and autonomous business execution are not implemented.
