# ADR 0043: Catalog investigations use scoped evidence and reviewed delivery

Status: implemented and scoped verification passed for Phase 15H, including real
local Qwen. Deployed and final release acceptance remain pending.

The existing Analyst performs native model-selected MCP calls under the current
Master session. Dedicated read-only Catalog tools reuse the exact-source 15G
application APIs. Source scope is rechecked during execution, on result reads and
before publication. New evidence never enters legacy Worker-less references.
Separate business/simulation selection prevents a demonstration investigation
from silently querying ordinary business disclosures.

Planning narrows discovered tools and checks copied observed references; it never
creates authority or executes a business operation. The model still selects each
native call and argument. Price/cost comparisons invoke deterministic arithmetic;
accepted-line and cost descriptions invoke the existing scientific service. Missing
values, incompatible scopes and incomplete sources remain explicit. Financial
facts bind amounts to source companies and monetary labels. Publication is a
separate explicit human action, not an MCP tool.

Native call frames are retained in their original activity transcript. Concise
model views remove repeated layout, configuration fingerprints and full unit
proofs while preserving relevant facts, exact source references, unknowns and
leases. Deterministic services use complete original evidence rather than these
presentation views. Per-call deadlines, total time, steps, calls and context
budgets remain independent.

Actual Qwen testing exposed both oversized context and malformed native array
calls. The parser correctly produced no executable call; no prose-to-call fallback
or JSON repair is permitted. A generation-only diagnostic reconstructed retained
source frames (not a byte-identical original request) and its raw token trace
showed the missing outer JSON brace. An additive named-pair input subsequently
produced a valid native response in a focused diagnostic. Both inputs resolve to
the same existing full-reference calculation API; the original array contract
remains available. A diagnostic is not an end-to-end acceptance result.

The immutable calculation/finding link uses existing platform migration 19 and
existing signed durable finding synchronization. Publication locks the current
reviewer's role, source records and calculation identity, and rechecks complete
arithmetic and leases. Concurrent retries retain one finding. Current Master
views require authority over every contributing source, rather than returning a
cross-company narrative to a partially scoped account.

Delivery targets exact original Worker installations, including when an entity
owns several Workers. Each packet contains only that Worker's observations and
references. The receiving Worker checks original verified module identity and its
declared read permission on every view/acknowledgment. It needs no Master runtime
connection for local operation or durable acknowledgment. Existing mission and
economic privacy boundaries remain separate and unchanged.

Quantity-only descriptions and incomplete financial calculations cannot become
financial recommendations. No tool activates a price, publishes a storefront,
orders goods, creates a financial commitment or authorizes production. Real-model
and simulator verification establish neither live commerce mutation compatibility
nor commercial production readiness.
