# 0030 — Governed mission capacity and analytical review

Status: accepted design; deployment acceptance is recorded separately.

Shared Workforce catalog totals do not establish a programme's entitlement.
Workforce owns explicit, reviewed allocations to an exact enrolled entity,
installation, module and programme. Allocations reserve unused capacity against
other consumers, including legacy enrollment paths. Existing claims survive
revocation; capacity cannot be implicitly transferred to replacement providers.
Programme-specific reads use an optional signed SSMA capability and the existing
bilateral routing and approval system. Missing, changed or stale authority is
unknown, never zero. Independently packaged older modules remain supported.

Employment may include approved, fresh programme capacity in its first sealed
aggregate. New optional version-one metrics permit older releases to omit them;
omission means unknown. Existing sealed cohorts are never rewritten to populate
new fields. Participant unresolved-referral observations use authoritative
cutoff timestamps and the existing whole-vector suppression policy. Food stock
shortage observations explicitly describe local resource stocks, not recipients
or unknown external availability.

Alternative mission scenarios must use the same fixed source references,
programme, service and currency. Each alternative invokes the existing exact-cent
calculation and scientific service. A comparison retains the actual child
calculations and their evidence; it is not an additional scientific computation.
Neither source money nor participant counts are summed across alternatives.
Model output must preserve each alternative's calculated values. Finding
publication remains a separate authorized review.

Operational reviews evaluate fixed predicates over expressly disclosed aggregate
observations. They do not query cases, derive hidden complements, modify source
records or run a new background monitoring subsystem. Unknown evidence produces
an insufficient-evidence result. Only actual alerts can be explicitly reviewed
and published; their evidence snapshot and durable delivery are restricted to
the affected source installations. Current programme authorization continues to
govern retained reviews, comparisons and findings.

These choices reuse module databases, SSMA, disclosure leases, retained mission
calculation storage, synchronization and SSDS presentation. They do not introduce
an alternative authority mechanism, autonomous service decisions, payments or
commercial production authorization.
