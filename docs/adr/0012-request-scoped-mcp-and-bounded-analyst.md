# 0012 — Request-scoped MCP and bounded analysis

Status: accepted for Phase 5.

Use the official MCP TypeScript v2 SDK, pinned server/client 2.3.1, Fastify adapter 2.0.1 and Node adapter 2.1.1 (the lockfile is authoritative). Fastify retains its HTTPS listener, session authentication, CSRF checks, body limits, and error handling. The official `createMcpHandler`/`toNodeHandler` bridge serves Streamable HTTP at `/api/v5/mcp`. A fresh server is built per authenticated request; no transport/session object is shared across principals. Stateless requests rediscover capabilities from current permissions and active signed manifests.

Approved application clients use existing local administrator sessions plus Origin/CSRF and a constrained client label. The internal Analyst label additionally requires a session-bound, ten-second HMAC process proof with nonce replay protection; external callers cannot impersonate that identity. It grants no additional user authority. No OAuth authorization server or unattended service credentials are introduced. External clients must first use the existing trusted HTTPS login. They must retain session and CSRF secrets outside their model context. Worker enrollment certificates do not grant analytical access. Master analysis uses already disclosed, scoped synchronized projections, preserving source installation, revision and freshness; live cross-Worker delegation is deliberately not introduced.

MCP tools call existing application services in process, preserving their authentication and disclosure checks. The Analyst is a genuine HTTPS MCP client, including initialization, discovery, invocation and protocol errors. Its server-side TLS self-connection verifies the operator's CA and hostname, never disabling certificate verification. Sessions never enter provider requests. Signed manifest `mcpTools` contributions map only to declared parameterless GET operations, with permissions enforced again by the existing module gateway. No contributed executable code, URL, HTML or assets are loaded.

The Analyst is a bounded loop with a provider-independent interface and a Responses wire adapter. Endpoint, credentials, trust, model and budgets are operator configuration. Tool data is untrusted; tools are read-only, names and arguments are validated, outputs are size bounded, repeated calls and excessive steps are rejected. Provider or tool failures preserve partial audit and cannot affect ordinary business transactions. An explicit human action creates findings through the existing idempotent finding service and durable synchronization.

Deterministic resource sharing is a separately testable TypeScript capability. Source records establish volume, currency and external expense. Internal payment, incremental cost, transition, avoidable expense fraction and location approval are explicit assumptions. Total observed warehouse operating expense cannot establish incremental cost. Internal payments cancel at ecosystem level; one-time transition is charged once. Recommendations execute no business action.

An explicitly configured HTTPS protocol fixture exercises actual application records and genuine MCP in automated and browser verification. Its identity is persisted and displayed as TEST MODEL. It is never a runtime fallback. Separate live-provider validation requires operator credentials; lack of those credentials must be reported rather than replaced with fabricated AI analysis.
