# v0.9.1 acceptance record

Baseline: verified v0.9.0, commit `66481a9fedf5047c38972fc481dbdad358b16916`. Development branch: `ux/v0.9.1-business-intelligence`.

Implementation and acceptance are in progress. This document is not a release declaration. Mandatory browser, deployment regression, installation and packaging gates must pass before tagging.

## Preservation evidence

The synthetic `.steward/ux-release-acceptance` deployment was upgraded through a private image-selection overlay. Before/after comparison passed for 104 private files; existing account/password hashes, installation/enrollment identities, module state/configuration, all protected module business tables and retained Master evidence/findings/investigations were unchanged (`artifacts/bi-preservation.json`). No credentials were reset. Earlier deployments and the published 0.9.0 bundle were preserved.

## Implementation scope

Evidence-derived executive opportunities, deterministic priority, a paginated investigation catalog, readable finding detail, independent AI status, source-backed per-company/per-currency financial reports, company performance, and shared module presentation/navigation refinements. The generic modular renderer remains in use. See ADR 0022 for provenance, scope and financial selection rules.

## Limitations carried forward

Commerce acceptance uses authenticated local simulators. Live Shopify/Printify connectivity and paid production are not certified or exercised. Catalog/shipping quotes remain estimates. Financial reporting is a bounded source selection, not an audited accounting statement. Confidence and urgency remain unspecified when absent from evidence. AI narratives require human review against source records and deterministic calculations. Provider secrets remain deployment-managed. Passing a demonstration does not establish commercial production readiness.
